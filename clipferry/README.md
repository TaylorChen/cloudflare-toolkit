# ClipFerry

ClipFerry is a lightweight cross-device text clipboard tool built on Cloudflare Workers and Cloudflare KV.

Open the same room on multiple devices, read/send text from one device, then copy it from another.

## Features

- Text-only clipboard sharing
- No account or login
- Recent 5 text items
- 5-minute automatic expiry
- Mobile-friendly single page UI
- Clipboard read/write buttons for HTTPS browsers
- Share link and QR code
- Room token access control
- Browser-side AES-GCM encryption
- Worker-level rate limits and room quotas

## Security Notice

Room links include a secret after `#`. The Worker only stores a token hash and encrypted text payloads.

Keep the full share link private. Anyone with the full link can access that room until it expires.

## Cost Controls

ClipFerry includes conservative Worker-side controls:

- Room expiry: 5 minutes
- Recent history: 5 text items
- Text item max: 64 KiB before encryption overhead
- Room storage max: 512 KiB of active history
- Polling interval: 5 seconds, paused when the tab is hidden
- Room creation limit: 30 rooms per IP/user-agent per hour
- Room read limit: 90 API reads per room token per minute
- Room write limit: 20 writes per room token per minute

For production, also add Cloudflare-side controls:

- WAF rate limiting for `/api/*`
- Bot Fight Mode or Turnstile if abuse appears
- Usage alerts for Workers and KV

## API

```text
GET  /                  Redirects to a random room with a URL hash secret
GET  /:room             Web UI
GET  /api/rooms/:room   Returns recent encrypted text items
POST /api/rooms/:room/items
```

API requests must send the room token hash:

```text
X-Room-Token: <sha256(token:<url-hash-secret>)>
```

`POST /api/rooms/:room/items` accepts encrypted text JSON generated by the browser.
